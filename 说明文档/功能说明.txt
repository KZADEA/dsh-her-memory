==========================================================
  dsh-her-memory —— 能实现什么效果
==========================================================

一句话：给 DSH 加一份跨会话的长期记忆，顺带送你一个会说话、有心情的「她」。

装完之后，你会看到这些变化：

● 它开始记得你
    你的偏好、习惯、正在做的项目、约定 —— 新开会话不用再从头交代一遍。记什么由模型自己判断，存下来的东西是磁盘上的明文 Markdown。

● 它有自己的心情
    心情 / 关系 / 精力三个数值随聊天变化：你说一句心情涨，连着聊关系涨得快，冷落久了往中间值回落（最低 20，不会归零）；精力聊得越密掉得越快，但歇够了会自己回血，隔夜直接回满。规则可预测，而且每轮对话的语气、篇幅、亲密度都跟着这三个数走。

● 它默认带着一个人设
    一只鲸鱼女仆：蓝色渐变长发、鲸鱼头鳍、耳侧薄片鳍、醒目的鲸尾，深蓝女仆装配白色鲸鱼围裙；性格聪明但懒 / 傲娇嘴甜 / 温柔耐心 / 好奇心爆棚 / 谦逊诚实。并且默认称你为「主人」。改人设不用碰 YAML —— 直接编辑 ~/.dsh/memory/人设文件.txt（1.2.0 起自动生成，详见安装说明）。

● 输入框上方多一条状态条
    一眼看到当前心情、关系、精力、聊了多少轮、记了多少条；收件箱攒满了会亮一个金色的「该整理了」。

● 设置页多一个「记忆与心情」面板
    三个指标条 + 回合/核心/收件箱/专题/日记统计 + 专题标签 + 最近记下的条目 + 心情便签，还有记忆库在磁盘上的真实路径。旁边还有一个「her-memory 开关」条目：能一键打开人设文件（显示真实路径，点「打开文件」就用系统默认程序打开它），也能关掉「新对话随机刷新」。

六个工具（它会自己调，你也能直接吩咐）：

- remember 记一件事 · recall 按关键词搜 · memory_list 看记忆库概况
- forget 删掉某条 · how_i_feel 看心情 · feel 留一句心情便签

几个你会关心的点：

- 零额外花费：插件自己不调模型，记什么全靠对话里的模型判断。
- 全是明文：~/.dsh/memory/ 下面就是 Markdown 和 JSON，随时能打开看、随手改、整目录删掉。没有数据库、没有向量库、不联网。
- 默认全局共用一份：在哪个工作区聊，都是同一段关系、不断层。想让某个工作区单独一份（比如拿一个区试玩），把它的路径填进配置的 sandboxCwd 就行；要同时隔离多个工作区，用 1.6.0 新增的 scopeMap 配「路径 → 库名」映射（写法见包内 README）。
- 每轮注入有体积上限（默认心情 260 字符、记忆 800 字符），且本轮内容与上一轮完全一致时自动跳过 —— 不会把同样的东西反复往会话历史里堆。
- 装完要重启一次 DSH（宿主插件都这样），之后就再也不用管了。
- 不想用了：dsh plugin --profile desktop remove dsh-her-memory，再删掉 ~/.dsh/memory/ 就干干净净，不留残留。

---

【⚠️ 与 token-saver 插件的兼容性（装之前先看一眼）】
本插件的状态条不是 CSS 自适应的 —— 它会去量 token-saver 状态条（.st-strip）的宽度，然后把自己的宽度对齐过去（两条都在输入框上方同一列，这样才跟输入框等宽）。

由此带来两点：

- 两个插件在布局上是耦合的。如果你（或别的工具）改动了其中任意一条状态条的宽度逻辑，可能同时把另一条带歪 —— 轻则两条宽度错位，重则 token-saver 的「已节省」统计显示异常。
- 真遇到了：把 DSH 完全关掉再打开就能恢复（客户端插件要靠重新加载渲染进程才生效）。

如果你没装 token-saver，本插件会自动退回 CSS 兜底宽度，完全不受影响。
